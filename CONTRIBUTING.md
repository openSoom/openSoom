# Contributing

Start with the README's pinned checkout installation and account-free fixture. Keep facility targets in profiles and vendor conversions in adapters. Explain the operating problem, smallest change and observed result in a pull request. Include a focused behavioral test when a contract, failure path or permission boundary changes.

Run `uv run --no-sync pytest -q`. Runtime checks in `scripts/` require their named CSE profiles and may start/stop project-local processes. Do not use real equipment or external model calls without configured scope and allowance. Never reset the shared LLM accounting database to obtain extra test capacity.

Source contributions use Apache-2.0. Original documentation/media use CC BY 4.0. Keep third-party notices and cite external sources. Do not commit `.runtime/`, `.env`, private keys, organizer attachments, personal account data or generated Codex profiles.

Reviewers distinguish implementation evidence, captured runtime behavior and independent verification. A picture, plan, command write or fixture cannot stand in for a live model outcome. Keep failed attempts where they explain a fix, and state which capture supersedes them.

See `AGENTS.md`, the implementation plan and review ledger for the project's four-team review procedure. Reporting a concern in this repository does not authorize contacting external people or publishing a submission elsewhere.
