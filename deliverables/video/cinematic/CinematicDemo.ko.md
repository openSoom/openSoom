# openSoom · CinematicDemo 편집 지시안

두 영상은 영어로 제작한다. 45초 PR은 운영자가 처음 질문을 던지는 순간부터 다음 행동이 정해지는 순간까지를 보여준다. 5분 데모는 심사위원이 같은 판단을 화면과 실행 기록에서 직접 확인할 수 있도록 구성한다. 원고와 재현 방법은 [PR 편집 폴더](pr/) 및 [데모 장면표](demo/README.md)에 있다.

## 45초 PR

| 구간 | 편집 의도와 사용 화면 |
| --- | --- |
| 0:00–0:05 | Firefly로 생성한 주방 후드의 실제 모션 클립. 팬 가동 소식과 “Is the air moving?” 사이에 쉼을 둔다. |
| 0:05–0:10 | 설비 매크로 컷에 조리 라인의 가상 풍량 **360 m³/h**와 해당 시설 목표 **900 m³/h**를 배치한다. 현장 이미지는 예시이고 수치는 시뮬레이터 관측이다. |
| 0:10–0:13 | 실제 앱 화면으로 전환해 한 관측이 들어오는 맥락을 잡는다. |
| 0:13–0:21.5 | 하나의 CSE 이벤트가 운영 앱과 정비 앱에 전달되는 경로를 그린다. 두 앱은 같은 CIN을 각각 읽는다. 운영 앱은 댐퍼 명령과 결과를 추적하고, 정비 앱은 점검 업무를 남긴다. |
| 0:21.5–0:29 | 실제 운영 화면에서 댐퍼 수신 확인과 미회복 풍량 **360/900**을 함께 보여준다. 별도 운영·정비 프로세스 실험과 대시보드의 실행 ID를 구분한다. |
| 0:29–0:38.5 | Firefly 학습 시설 영상에서 실제 학습 시설 앱으로 전환한다. 이 프로필에서 확인할 값은 **200/500 m³/h**다. |
| 0:38.5–0:45 | oneM2M과 openSoom 브랜드를 정리하고 저장소 주소가 읽히도록 고정한다. 원본 영어 음성의 문장 사이 여백을 이용해 장면에 맞췄다. |

## 5분 발표 데모

심사 발표 전체는 12분으로 연습한다. **3:10에 화면과 시스템 소리를 공유해 데모 영상을 시작하고 8:10에 발표자가 이어간다.** 45초 PR은 Hackster 첫 화면용이다.

1. **0:00–0:33** — 주방의 운영 질문과 실제 성능평가 출처. 평가 대상 301곳이라는 범위를 수치와 함께 제시한다.
2. **0:33–1:19** — 실제 브라우저에서 가상 식품 생산 라인을 선택하고 조치 후 관측으로 회복 여부를 확인한다. 시작 360, 목표 900, 최종 1,035 m³/h다.
3. **1:19–1:39** — 장치 MQTT/TLS 생성과 관리 앱 HTTPS 읽기의 리소스 ID를 대조한다. 보안 구성에서 남긴 별도 실행 기록을 쓴다.
4. **1:39–2:25** — 가상 학습 시설을 실제 UI에서 조작한다. 댐퍼 ACK를 받았어도 200 m³/h가 목표 500에 못 미쳐 미해결로 남는다.
5. **2:25–3:37** — 같은 CIN을 읽은 두 실제 앱의 영수증을 재구성한 그래픽, 서로 다른 업무 기록, 권한이 거부된 요청을 보여준다. 식품·학습 대시보드 실행과 독립된 HTTP 로컬 실험이다.
6. **3:37–4:46** — 실제 모델의 도구 선택과 후속 확인, 별도 중앙 장애 실험, 두 번째 공급사의 단위 매핑과 소스 설치 경로를 보여준다.
7. **4:46–5:00** — 저장소를 안내한다. 샘플 장비는 가상이고 소프트웨어 실행과 공개 기록은 실제다.

## 다시 편집할 때 지킬 증거

- 새 장면의 숫자는 시설·구역·실행 ID가 일치하는 기록에서 가져온다. PR의 조리 라인 미해결과 5분판의 조리 라인 회복은 서로 다른 브라우저 녹화다. [PR 녹화 기록](../../../evidence/video/cinematic/pr-dashboard-recording.json) · [두 시설 녹화 기록](../../../evidence/video/cinematic/dashboard-recordings.json)
- 영상에 등장하는 복수 앱 실행은 `ma-d1a54f066e`다. 이후 검토에서 끊긴 관측 구간의 연속 샘플 카운터를 수정하고 새 소스로 세 시나리오를 다시 실행했다. 이전 촬영물의 ID를 바꾸지 않는다. [촬영 근거](../../../evidence/runtime/multiapp/index.json) · [수정 후 실행](../../../evidence/runtime/multiapp-revalidation/index.json)
- Firefly 컷에는 예시 장면 표시를 유지하고 실제 현장 촬영·실물 성능 개선으로 표현하지 않는다. 실제 대시보드 화면, CSE 기록을 읽어 그린 도식, 실제 LLM 기록의 구분을 유지한다.
- Adobe 생성 요청은 주방·설비·학습실의 움직이는 장면 세 개에 집중했다. 원곡은 45초 전용으로 생성했고, 영어 내레이션과 선택형 영어 자막을 같은 발화에 맞춘다. [제작 기록과 크레딧 집계](../../../evidence/video/cinematic/adobe-production.json)
- 후속 편집은 기존 소스를 먼저 재사용한다. 다음에 유료 배경 영상을 새로 만들 때의 기본값은 **720p·24fps**다. 실제 UI·타이포그래피·완성본은 1080p를 유지할 수 있다. 이번 5초 3컷은 1080p에서 1,500크레딧이었고 같은 분량의 720p 단가는 750크레딧이다. [Adobe 공식 단가](https://helpx.adobe.com/creative-cloud/apps/generative-ai/generative-credits-faq.html)
