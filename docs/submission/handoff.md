# openSoom submission handoff

The final English project film follows the supervisor who keeps a particle alert open, then a separate low-flow incident where maintenance changes the first inspection using an independent MEC measurement. The equipment is virtual. The local ACME and recorded cloud ETSI Sandbox executions have distinct run IDs.

## Submit the public project on Friday, 20 November

1. Download and extract the [submission ZIP](../../deliverables/openSoom-submission.zip). Open `START-HERE.html`. It contains the copy-ready English title, description, video-upload text, Discord message and links below. The extracted `Hackster/story.html` supplies the formatted article.
2. Upload the English MP4 to YouTube or Vimeo, choose public or unlisted access, and paste its URL into the Hackster Story editor. The extracted MP4 includes visible captions and the separate English SRT is ready for upload. The repository provides an additional direct MP4 download. [Platform instructions](https://help.hackster.io/en/articles/1895235-how-do-i-add-a-video-to-my-project)
3. Publish the English Hackster article with the cover, story, video and repository link. Check in a signed-out browser that it opens and plays. Post the new public article URL in the team Discord channel. Add the public backlink near the top of the repository README after that URL exists. [Article](hackster-article.md) · [Fields and asset map](hackster-publish-notes.md) · [Public source](https://github.com/openSoom/openSoom)
4. In the evaluation sheet, put **openSoom** in column C and the published Hackster URL in D. Mark **X** in G–AJ for the slots you are available for. The organizer marks the final slot **PICK**. [Evaluation schedule](https://docs.google.com/spreadsheets/d/1x1husd3She4ixkpxVvUy4LZJ75F2QFRDIpocEdst7p8/edit?gid=0#gid=0)

## Submit the English presentation by Sunday, 22 November

Upload the [PPTX](../../deliverables/presentation/openSoom-evaluation.pptx) to the organizer’s folder. The [PDF](../../deliverables/presentation/openSoom-evaluation.pdf) and [MP4](../../deliverables/video/openSoom-air-quality-720p.mp4) are available as offline backups. Join before the assigned interview slot on 23–25 November. Each team has 20 minutes, including a 10–15 minute talk with the demo and time for the judges’ questions. The scripts reserve audience time to read the pollutant readings, compare the two decisions and inspect the original work order.
