group fan-out with preserved failure boundaries, native MQTT/TLS and HTTPS,

expiry/profile/replay checks. These are virtual devices and a local software
lab; physical ventilation effectiveness and production authentication are
not established.

logical modules, native resource groups and virtual devices. The Korean guide
and English article/video preserve those boundaries.
